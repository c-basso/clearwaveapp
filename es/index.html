Preguntas Frecuentes

¿Esto dañará mis altavoces?

No, las ondas sonoras son seguras y no dañarán tus altavoces. Es básicamente lo mismo que reproducir música en tu teléfono, pero con frecuencias cuidadosamente calibradas diseñadas específicamente para la expulsión de agua.

¿Esto funciona en todos los dispositivos?

Clear Wave funciona en dispositivos iPhone e iPad. La aplicación está optimizada para iOS y proporciona los mejores resultados en hardware Apple. Requiere iOS 15.1 o posterior.

¿Cuánto tiempo debo reproducir el sonido para eliminar el agua?

Generalmente 10-30 segundos es suficiente, pero puedes repetir el proceso si es necesario. Puedes probar el volumen de tus altavoces después de cada ciclo para verificar si el sonido ha mejorado.

¿Qué pasa si la expulsión de agua no funciona?

Si la expulsión de agua no funciona inmediatamente, intenta repetir el proceso 2-3 veces. Para agua persistente, también puedes probar el generador de tonos de frecuencia en diferentes frecuencias. Si el problema persiste, podría indicar daño de hardware que requiere reparación profesional.

¿La aplicación es gratuita?

Clear Wave es gratuita para descargar con funciones básicas de expulsión de agua. Las funciones premium como el generador de tonos avanzado están disponibles a través de compras dentro de la aplicación para usuarios avanzados.

¿Puedo usar esto para otras pruebas de audio?

¡Sí! Clear Wave incluye herramientas de audio profesionales para probar la audición, afinar equipos de audio, monitorear niveles de ruido y verificar el balance de canales estéreo, convirtiéndola en un kit de herramientas de audio todo en uno.
